# hbm_sim 维护说明

本项目的主线是“仿真平台 + 堆叠存储模型”，不是只有时序的控制器原型。

## 权威文档

- [README.md](README.md)：项目入口。
- [堆叠存储模型交付手册](堆叠存储模型交付手册.md)：保持章节完整的说明书，含常用操作、原理和结果判断。
- [项目指南](文档/项目指南.md)：架构、构建、运行、后端、热模型、测试和代码索引。
- [cfg指南](文档/cfg指南.md)：完整配置字典、使用方法及主输入/派生参数联动。
- [输出指南](文档/输出指南.md)：普通报告、全输出字段、产物和性能分析。
- [审计](文档/审计.md)：来源、验证证据与器件校准边界。

## 当前实现

- `MemoryImage` 管理行缓冲、物理坐标、ECC、功耗和热模型语义。
- `MemoryBackend` 管理数据、初始化标记和元数据，支持 `sparse`、
  `mmap_sparse`、`chunk_file`。
- CLI 默认使用流式 `TrafficStream`，不会先构造完整的大型请求数组。
- `BW/BR` 按逻辑数据块展开；`check=last_write` 使用最近一次写入作为期望值。
- 命令和 DFI 验证属于离线审计。DFI 结构检查是自洽验证；只有请求提供
  `expect=` 时，读数据才有独立期望值。
- Ramulator2.1 只作为共同命令面的外部参考，不是本项目的实现裁决者。

## 文档规则

- 交付手册保留完整章节、常用操作和必要原理，不简化成链接目录；详细参数/指标字典分别归 cfg/输出指南。
- 文档目录只保留上述四份指南，各自维护所属详细内容；其他目录 README 只说明本目录。
- 使用仓库相对路径，不写本机绝对路径。
- 不把研究默认值表述为厂商校准数据。
- 修改实现后同步更新相关权威文档、目录 README 和测试说明。

# UCIe 接入前整改与验证

日期：2026-09-07。承接 `bf355a4` 的评审结论，目标是完成接入前组件和接口门禁。
本轮未实例化真实 UcieLink/PHY，也未实现存储目标端，因此不作为端到端验收报告。

## 1. 已完成的整改

| 问题 | 实现与验证 |
|---|---|
| 缺少完整250B线格式 | AouWireFlit及PH编解码；独立黄金字节、逐位测试、完整PLP检查 |
| 接收依赖used_granules | DUT与独立TB扫描器均按MsgStart/首字节/carry定界，双向功能测试只传250B |
| 接入指南物理布局不准确 | 按图4更正PH散布和126/254两组CRC槽位；新增共享scatter/gather |
| UCIe只支持236B/64B | 保留原格式，新增AouFormat6/aou256；build/check/unpack和长度契约同步 |
| 接口与适配延迟未定 | 保留桥ready/valid，UCIe侧Endpoint；TX新增0拍、RX holding1拍，训练门控 |
| 双方速率可能48/96GB/s不一致 | 共用link_config，默认x16/24G/NRZ；不匹配配置拒绝；替代参数重编测试 |
| 中途复位残留顺序/FIFO/credit | 清五类消息队列、路由、credit事件、顺序表和局部状态；1/2/4 RP恢复测试 |
| AXI非法输入行为未定义 | AW/AR/W入口fail-fast；三位宽各12个真实端口负向场景 |
| credit事件FIFO阻塞线程 | 非阻塞发送并保留holding；RP4一次80事件及后续连续Flit压力测试 |
| golden覆盖描述过强 | 明确原71项是消息golden；PH/PLP/物理位置由wire-all另行验证 |
| 构建/交付可复现性 | 根目录preflight、共享SystemC路径、report传播失败、参数变更重编、reference补丁及只读安装检查 |

原详细中文注释主要保留；迁移的解析说明集中到 `aou_stream_decoder.h`，新文件均
注明职责、字段语义和限制。新存储公共类型在 `simple_mem_if.h`，其实际目标模型尚未实现。

## 2. 回归结果

入口：项目根目录 `make preflight`。它顺序执行所有门禁，任何失败均返回非零。

| 测试 | 结果 |
|---|---|
| 原功能TC1～TC9，三位宽 | 全通过，双向均经过250B编解码 |
| 消息golden，三位宽 | 每位宽71通过/0失败 |
| 线格式wire-all | 1378 / 1418 / 1500通过，均0失败 |
| 本地系统边界 | 三位宽×1/2/4 RP共9组通过；负向共36组通过 |
| 适配器与格式组件 | 4199通过/0失败，双向各256包，FIFO深度1 |
| 原UCIe单元测试 | 22通过/0失败 |
| 替代配置 | x8/PAM4/TAT80ns的组件与本地桥通过 |
| 性能，三位宽 | 原门限全通过 |

1024-bit默认配置：读42.66 GB/s、写42.40 GB/s；口径B分别94.79%和94.22%。
40ns TAT注入后吞吐保持100%。这些性能数值仍属于原 LinkPacer/RemoteAouModel
平台；新Endpoint与真实UCIe的排队/PHY延迟需要下一阶段单独测量。

测试详细判据见 [verification.md](../../systemc/doc/verification.md)，接口和字节表见
[wire_contract.md](../../systemc/doc/wire_contract.md)。参考补丁安装说明见
[integration/README.md](../../systemc/integration/README.md)。

## 3. 接入基线与下一阶段

基线：单RP默认，可选1～4；AXI256/512/1024；FDId0、VC0；FDI固定250B；物理
Format6为256B；x16/24G/NRZ；口径B以240B数据区归一化。不得把RP放入不受PHY保护
的VC元数据，也不得把对象辅助字段作为线上协议。

FH序号/replay与CRC16-CCITT沿用参考链路行为抽象，仅字节位置对齐AoU图4，
尚不是完整UCIe DLL标准实现。本地协调复位通过不意味着链路可单端热复位。

接入前门禁完成后，可以进入下一阶段：

1. 用四个FDI FIFO接上UcieLink，先验证250B链路传输与错误重放。
2. 实现简单存储目标的WREQ/WDATA配对、整burst缓存、WSTRB、R/B生成与credit归还。
3. 加入AXI端到端scoreboard、并发读写、随机背压和错误注入；测量真实TAT及分段延迟。

完整Activation/CSR、QoS三模式、防饿死、链路热复位、FDI cancel/stall和Flit2DFI
保持后续扩展范围，不纳入此次接入前门禁，也不宣称已经完成。
